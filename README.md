# Supermarket Sales - Exploratory Data Analysis

## Project Description
This project performs Exploratory Data Analysis (EDA)
on a Supermarket Sales dataset to identify patterns,
trends, and meaningful business insights.

## Objective
To analyze supermarket sales data using statistical
methods and data visualization.

## Dataset
Supermarket Sales Dataset from Kaggle.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Analysis
- Data Cleaning
- Statistical Summary
- Product Line Analysis
- Payment Method Analysis
- Customer Type Analysis
- Correlation Analysis

## Visualizations
- Product Sales Chart
- Payment Distribution
- Sales Histogram
- Customer Type Analysis
- Correlation Heatmap

## How to Run

1. Clone this repository.
2. Install the required libraries.
3. Run the Python file.

```bash
pip install -r requirements.txt
python eda_analysis.py
